# cpp-systems

Small, focused implementations of core systems programming concepts in modern C++.

This repository is a personal learning / reference collection. Each program explores the internal mechanics of a fundamental building block (containers, allocators, memory management, etc.). The goal is understanding, not production use.

## Programs

- basic vector
- basic malloc on stack
- basic bump allocator
- basic memory pool
- basic unique_ptr
- basic spin-lock mutex
- basic lock-free ring buffer
